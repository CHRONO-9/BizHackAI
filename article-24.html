「取引先から送られてきた契約書、このままサインして本当に大丈夫だろうか……」。社内に法務部がない中小企業や一人起業家にとって、難解な法律用語が並ぶ契約書のチェックは最大のストレス源です。生成AIを活用して、自社に不利な「地雷条項」を5分で浮き彫りにし、相手の機嫌を損ねずに修正交渉できる「プロ仕様の対案プロンプト」を公開します。

⚡ 10秒お試し：ChatGPTにこのまま投げるだけ！ 
# あなたの役割
あなたは企業の法務コンサルタントおよび契約実務のエキスパートです。
以下の契約書ドラフトを詳細にレビューし、当事者である【自社（受託側/乙）】の立場から見て、不当に不利な条項や法的なリスク、曖昧な表現を抽出してください。

# 重点チェック項目
1. 損害賠償責任の範囲（上限の有無、直接損害に限定されているか）
2. 秘密保持の対象範囲および保持期間（一方的になっていないか）
3. 成果物の権利帰属（著作権・特許権が一方的に相手に移転していないか、著作者人格権の不行使条項）
4. 契約の解除条件（相手側からの一方的・即時解除条項がないか）
5. 支払い期日・検収基準（検収合格とみなす期日が明確か）

# 出力フォーマット
1. 【総合リスク判定】：（高 / 中 / 低）とその要約理由
2. 【要修正条項リスト】：
   - 条文番号と該当箇所
   - 指摘理由（どのような実害・リスクが想定されるか）
   - 推奨される修正案（条文の差し替えテキスト）

1. 契約書チェックを放置すると起きる「3大リスク」

「相手は大企業だから大丈夫だろう」「テンプレート通りだろう」と盲目的に署名・押印してしまうのは非常に危険です。特に以下の3つの条項には注意が必要です。

01

損害賠償の青天井

賠償上限が「委託料の額」等に限定されておらず、万が一の際に数千万円を請求されるリスク。

02

知的財産権の丸獲られ

自分が開発・制作した素材やノウハウの権利まで相手方にすべて譲渡させられる条項。

03

過度な競業避止義務

契約終了後も同業種での活動が制限され、他のクライアントと取引できなくなる罠。

2. AIに契約書を読ませる前の「情報マスキング」鉄則

AIに契約書をレビューさせる際、「機密情報の漏洩」を絶対に防がなければなりません。ChatGPTに入力する前に、必ず以下の単語をプレースホルダーに置き換えてください。

置換例（マスキングルール） 
自社名（株式会社アルファ） ➡ 【甲】または【自社】
相手先企業名（株式会社ベータ） ➡ 【乙】または【取引先】
金額（月額50万円、総額300万円） ➡ 【〇〇円】
特定の人名、住所、電話番号 ➡ 【担当者名】【住所】

※ChatGPTの「オプトアウト設定（Data Controlsで学習オフ）」を有効にしておくことも必須です。

3. 【本番運用】不利条項検知＆修正対案生成プロンプト（立場指定版）

冒頭の「10秒お試し版」で基本リスクを掴んだら、実務の本番確認では「自社の立場（受託側／委託側）」「みなし検収の有無」「管轄裁判所の偏り」まで網羅した以下の詳細版プロンプトを使用してください。

本番運用：契約書フルチェック＆対案作成プロンプト 
# 指示と前提条件
あなたは企業の法務審査を担当する契約実務スペシャリストです。
以下の契約書ドラフトを精査し、当事者である【自社の立場：受託側（乙）】にとって過度な不利益・片務性・想定外の損害リスクとなる条項を洗い出してください。

# 必須監査ポイント（全7項目）
1. 損害賠償の上限（委託料総額や直近〇ヶ月分を上限とする規定があるか／間接損害・逸失利益が除外されているか）
2. 知的財産権の帰属（開発前からの既存ノウハウ「背景知財」まで譲渡対象に含まれていないか）
3. 検収・支払い条件（成果物提出後、一定期間内に通知がなければ「検収合格とみなす」規定があるか）
4. 契約不適合責任（瑕疵担保）の期間（引渡し後6ヶ月〜1年以内に限定されているか）
5. 秘密保持期間（契約終了後3〜5年等の合理的な期限が切られているか／無期限になっていないか）
6. 中途解約・損害負担（相手方の都合で解約された際、既実施分の報酬が支払われるか）
7. 管轄裁判所（相手方の本店所在地のみに一方的に指定されていないか）

# 出力形式
1. 【リスク評価サマリー】（総合判定：高 / 中 / 低 ＋ 締結前に必ず交渉すべきトップ3）
2. 【条文別・詳細指摘表】
   - 該当条項・問題のある原文抜粋
   - 実務上の具体的リスク（最悪のケース）
   - 交渉用の修正対案（そのまま差し替えられる自然な条文テキスト）

# マスキング済み契約書テキスト
（ここに固有名詞を置換した契約書全文を貼り付け）

【実機検証】危険な業務委託契約条文のBefore / After実例

実際にフリーランス・制作会社がよく遭遇する危険な原文を上記プロンプトにかけた際の、AIによるリスク検知と修正対案の実例です。

❌ 危険な原文（Before：受託側に致命的な条文）：
「第12条（損害賠償）乙が本契約に違反し甲に損害を与えた場合、乙は甲が被った一切の損害（逸失利益および弁護士費用を含む）を直ちに賠償する責任を負う。」

✅ AIが生成した修正対案（After）：
「第12条（損害賠償）乙の責めに帰すべき事由により甲に損害が生じた場合、乙は甲に対し、現実に発生した通常かつ直接の損害に限り賠償責任を負うものとする。ただし、その賠償額の累計上限は、本契約に基づき甲が乙に支払った業務委託料の総額を超えないものとする。（故意または重過失がある場合を除く）」
💡 解説：青天井の賠償リスクと「逸失利益」の文言を削除し、委託料総額を上限とする業界標準の公平な条文へ変換。

4. 相手と揉めずに合意できる「修正対案・交渉メール」生成術

修正案が出たとしても、「この条文は不利なので直してください」とストレートに伝えると角が立ちます。AIに対案メールを作成させましょう。

修正依頼メール作成プロンプト 
# 依頼内容
先ほど検出された修正箇所に基づき、相手方の担当者に送る「契約書修正のお願いメール」を作成してください。

# トーン＆マナー
- 相手への感謝と取引開始への前向きな姿勢を明確にする
- 相手を責めるニュアンスを完全に排除し、「社内法務（顧問弁護士）の確認ルールに基づき、双方の公平性の観点から微修正をご相談させていただく」という建前をとる
- どの条文を、どのように、なぜ変更したいのかを箇条書きで分かりやすく整理する
📧 AIが生成した交渉メール完成例（そのまま使える実例）：
件名：業務委託契約書ドラフトのご確認・一部文言ご相談の件（株式会社〇〇）

〇〇株式会社 〇〇様
いつも大変お世話になっております。株式会社〇〇の〇〇です。
この度は契約書ドラフトをご送付いただき誠にありがとうございます。ぜひ前向きにプロジェクトを進めさせていただきたく存じます。

つきましては、弊社の社内確認プロセスにおきまして、双方の継続的・円滑な取引関係を担保する観点から、以下の2点のみ文言の微調整をご相談させていただけますでしょうか。
・第12条（損害賠償）：賠償範囲を通常かつ直接の損害とし、上限を本契約の委託料総額とする文言の追記
・第8条（検収）：納品後10営業日以内に書面でのご指摘がない場合は検収完了とみなす旨の明記

お手数をおかけいたしますが、修正案を反映した履歴付きファイルをお送りしますので、ご検討のほどよろしくお願い申し上げます。

5. 弁護士法72条（非弁行為）とAIレビューの正しい付き合い方

法律業務を扱う上で、弁護士法（非弁護士の法律事務の取扱い等の禁止）の理解は不可欠です。

⚠️ 法務上の重要注意事項
AIによる契約書レビューは「自社のリスク確認・思考の補助ツール（壁打ち）」として利用するものです。第三者に対して有償で法的判断を提供する行為や、数千万円規模の大型契約・複雑な係争事案においては、必ず顧問弁護士や弁護士ドットコム等の専門資格者による最終リーガルチェックを受けてください。
